# FatToFit - AI Health Buddy App

🏋️ **Your personal AI-powered fitness coach, nutritionist, and accountability partner.**

FatToFit is a React Native/Expo mobile app that combines real-time health data tracking, AI-powered coaching via OpenAI GPT-4, and comprehensive workout/nutrition management to guide users through their fitness transformation journey.

## Features

### 🤖 AI Coach
- 24/7 conversational AI coaching powered by OpenAI GPT-4
- Context-aware responses based on your health data, goals, and progress
- Personalized workout and nutrition recommendations
- Motivational support and accountability

### 📊 Health Tracking
- Automatic step counting and activity tracking
- Water intake logging
- Weight progress monitoring
- Sleep and heart rate data (when connected to HealthKit)

### 🍎 Nutrition Management
- Easy meal logging with calorie and macro tracking
- Daily calorie and protein targets based on your goals
- Meal templates for quick logging
- Visual macro breakdowns

### 💪 Workout Planning
- Personalized workout plans generated by AI
- Weekly schedule with progress tracking
- Workout logging with duration, calories, and perceived difficulty
- Exercise variety: Push, Pull, Legs, HIIT, Cardio, and more

### 📈 Progress Analytics
- Weight trend visualization
- Workout statistics and streaks
- Achievement system
- Weekly and monthly summaries

## Getting Started

### Prerequisites

- Node.js 18+
- Expo CLI (`npm install -g expo-cli`)
- iOS Simulator / Android Emulator / Expo Go app
- Supabase account (free tier works)
- OpenAI API key (for AI coaching)

### Installation

1. **Clone and install dependencies:**

```bash
cd health-tracker
npm install
```

2. **Set up Supabase:**

   - Create a new Supabase project at [supabase.com](https://supabase.com)
   - Go to SQL Editor and run the migration script: `supabase/migrations/001_initial_schema.sql`
   - Copy your project URL and anon key from Settings > API

3. **Configure environment:**

   Create a `.env` file in the project root:

```env
EXPO_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
```

4. **Update Supabase client:**

   Open `src/services/supabase.js` and replace the placeholder values with your actual Supabase credentials.

5. **Start the app:**

```bash
npm start
```

   Then scan the QR code with Expo Go (iOS/Android) or press `i` for iOS simulator / `a` for Android emulator.

## Supabase Setup

### Database Tables

The app uses the following tables:
- `user_profiles` - Extended user data and settings
- `health_metrics` - Time-series health data
- `meals` - Meal logging
- `meal_templates` - Saved/favorite meals
- `workout_plans` - Weekly workout plans
- `workouts` - Workout logs
- `chat_messages` - AI conversation history
- `achievements` - Unlocked achievements
- `daily_summaries` - Pre-computed daily stats
- `weight_history` - Weight tracking

Run the migration script in `supabase/migrations/001_initial_schema.sql` to create all tables with proper RLS policies.

### Row Level Security

All tables have RLS enabled. Users can only access their own data.

## AI Coach Configuration

### Using Your Own API Key

Users can enter their OpenAI API key during onboarding or in Settings. The key is stored securely and used for direct API calls.

### Supabase Edge Function (Recommended for Production)

For production, create a Supabase Edge Function to proxy OpenAI requests:

```typescript
// supabase/functions/coach-chat/index.ts
import { serve } from 'https://deno.land/std@0.168.0/http/server.ts'

serve(async (req) => {
  const { message, context, history } = await req.json()
  
  // Build system prompt with context
  // Call OpenAI API
  // Return response
})
```
